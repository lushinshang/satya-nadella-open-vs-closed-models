## 200字介紹

這篇導讀整理 Satya Nadella 的訪談：他不再相信對齊會隨模型規模自然出現，所以主張假設模型已遭入侵，把身分、日誌、政策與行為監控放在模型外面；對開放對封閉誰贏，他沒有宣布贏家，只說大部分 token 會商品化，前沿仍有市場；他也主張每家企業擁有自己的評測基準與軌跡。導讀把每個可查的說法對照官方文件，標出已確認、單一來源與與官方不符的部分，例如 Unilever 用 MAI 模型處理索賠只有訪談這一個來源，Lloyds 的「500 年」與官方歷史不符。講者是 Microsoft 執行長，相關產品都是自家產品，閱讀時要記得這個位置。
